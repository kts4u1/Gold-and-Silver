# 금·은 실물 최저가 (Gold-and-Silver)

골드바·실버바를 국내에서 **어디서 사야 가장 싼지** 실시간 시세로 비교하고 추천하는 웹앱입니다.
부가세·수수료·인출 비용까지 모두 더한 **실제 지불 총액**으로 순위를 매깁니다.

- 금/은 전환, 상품 중량(3.75g·10g·37.5g·100g·500g·1kg)과 수량을 고르면 구매처별 총액 순위와 추천 이유를 보여 줍니다.
- 오늘의 시세: 국제 금·은, 원/달러 환율, KRX 금시장, 최근 60거래일 추이 차트
- 금은방·금거래소 오늘 시세: 서울·경기·인천부터 부산·울산·대구·광주·창원·진주·구미·제주까지 사업자·개인 매장 27곳이 매일 고시하는 순금 1돈·은 3.75g 살 때/팔 때 가격과 18K·14K 매입가. 살 때 싼 순서로 정렬하고, 살 때 가장 싼 곳과 팔 때 가장 비싸게 사 주는 곳을 표시
- **내 주변 최저가 매장**: 사는 곳(시·도 → 시·군·구)을 고르거나 "현재 위치로 찾기"를 누르면, 사업자들이 공개한 전국 매장(이름·주소·전화·영업시간)에 오늘 가격을 붙여 집 근처에서 살 때 가장 싼 곳·팔 때 가장 비싸게 사 주는 곳을 보여 줍니다. 범위(같은 시·군·구 / 10·20·50km / 시·도 / 전국)와 정렬(살 때 싼 순 / 팔 때 비싼 순 / 가까운 순)을 바꿀 수 있고, 전국 매장 최저가·택배 골드바 최저가와도 비교해 줍니다. 범위 안에 매장이 없으면 가장 가까운 매장을 알려 줍니다
- 위치를 정하면 "최저가 찾기"에 구매처마다 "택배 배송 / 은행 영업점 · 전국 / 내 주변 매장 N곳 / 주변 매장 없음"이 표시되고, 내 주변에서 살 수 있는 곳만 골라 볼 수 있습니다
- g당 실질 가격 비교표: 중량과 상관없이 1g당 가장 싸게 사는 방법
- 내가 받은 견적 비교: 금은방·온라인몰 견적을 넣으면 순위에 함께 비교 (브라우저에만 저장)
- 수수료 설정: 거래하는 증권사의 KRX 수수료로 바꿔 계산
- 휴대폰 화면 대응, 다크 모드, 홈 화면에 추가(PWA) 가능

## 실행 방법

Node.js 20 이상이 필요합니다.

```bash
npm install
npm start          # http://localhost:3000
```

- 포트 변경: `PORT=8080 npm start`
- 회사망처럼 프록시를 거쳐야 하는 환경: `NODE_USE_ENV_PROXY=1 npm start` (Node 22.21 이상)
- 휴대폰에서 쓰기: PC와 같은 Wi-Fi에서 `http://<PC의 IP>:3000` 접속 → 브라우저 메뉴의 "홈 화면에 추가"

시세는 1분(조폐공사는 5분)마다 서버가 새로 가져오고, 화면은 1분마다 자동으로 갱신됩니다.

## GitHub Pages로 공개하기

서버 없이 `https://<아이디>.github.io/Gold-and-Silver/` 주소로 열 수 있습니다. GitHub Actions가 약 15분마다 시세를 모아 `data/prices.json`으로 저장하고, 화면과 함께 배포합니다 (`.github/workflows/pages.yml`).

**처음 한 번만 설정**

1. 저장소의 **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 선택합니다.
2. **Actions** 탭에서 `Deploy to GitHub Pages`를 열고 **Run workflow** 를 누릅니다 (이후에는 15분마다 자동 실행).
3. 완료되면 위 주소로 접속합니다.

**알아둘 점**

- 시세를 가져오는 서버가 해외(미국)에 있어서 일부 사이트가 막을 수 있습니다. 못 가져온 곳은 화면 아래 "데이터 출처"에 실패로 표시되고, 나머지 출처로 비교합니다. 가격이 하나도 없으면 배포하지 않고 이전 사이트를 그대로 둡니다.
- 화면 속 시세는 최대 15분 정도 늦을 수 있습니다. 실시간에 가까운 값이 필요하면 `npm start`로 직접 실행하세요.
- GitHub는 저장소에 활동이 60일 동안 없으면 예약 실행을 멈춥니다. 멈추면 Actions 탭에서 다시 켜면 됩니다.
- 예약 실행과 Pages 배포는 저장소의 **기본 브랜치**에서만 동작합니다. 기본 브랜치를 바꾸면 Settings → Environments → github-pages 의 배포 허용 브랜치도 확인하세요.
- 출처 한두 곳이 잠깐 열리지 않아도 매장·가격이 사라지지 않도록, 실패한 출처는 지금 배포된 사이트의 값을 이어 씁니다 (시세는 최대 48시간, 지점 목록은 최대 14일). 이어 쓴 값은 "지연"으로 표시됩니다.
- 내 컴퓨터에서 같은 결과물을 만들어 보려면 `npm run build` (결과: `dist/`).

- 한국표준금거래소 **본사 시세 API**도 연결해 두었지만 해외 IP를 막고 있어 여기서는 확인하지 못했습니다. 국내에서 실행하면 받아오고, 실패하면 "데이터 출처"에 경고로만 표시됩니다.
- 부산 지점은 홈페이지에 살 때 가격이 "VAT별도"로 표기되어 있어 표기대로 부가세 10%를 더해 비교합니다. 다른 거래소와 숫자가 거의 같아 실제로는 부가세 포함일 수 있으니 매장에 확인하세요.
- 금골디의 "살 때" 값은 기준 시각이 없고 국제 시세+부가세보다 낮게 나오는 경우가 있어 참고로만 보여 주고 구매 순위에는 넣지 않습니다.
- 매장 시세와 쇼핑몰 가격은 각 사이트가 자기 페이지에 보여 주는 공개 데이터이며, 사이트 부담을 줄이려고 10~15분에 한 번만 가져옵니다.

- **종로금거래소 "지점별 매입현황"**: 회원 로그인 전용이라 가져오지 않습니다. 같은 사이트의 "전국지점현황" 게시판은 유흥업소 스팸 글 수천 건으로 오염되어 있어, 사이드바의 정식 지사 이름 목록만 씁니다.
- **한국금거래소 소매 사이트·순금나라·한국기준금거래소**: 해외 접속 차단. 순금나라의 가맹점 목록 API는 열리지만 응답에 점주 계좌번호·로그인 아이디 같은 개인정보가 함께 들어 있어 쓰지 않고, 같은 가맹점이 실린 공개 매장 안내 페이지(goldshell)를 씁니다.
- **한국표준금거래소 본사 지점 목록**: 화면이 스크립트로만 그려지고 데이터 주소가 해외 접속을 막아 가져오지 못했습니다 (부산 지점 5곳만 포함).
- **한국금시장거래소 복사 사이트(starryjewelry)**: 오래된 시세가 그대로 있어 쓰지 않음
- **K GOLD 금거래소(청주·세종·동탄, kgold.kr)**: robots.txt가 자동 수집을 막아 둠
- **해외 접속을 막는 지방 매장들**: 한국감정금거래소 개인 사이트, 울산금거래소, 전주금거래소, 대전 세움, 천안 매장(imweb), 한국금거래소 지점별 사이트 등. 국내에서 실행하면 열릴 수 있습니다.
- **시세가 오래 멈춘 곳**: 한국대표금거래소(논산, 8월), 창원 cwgold(8월), 평택금거래소(8월), 고양 금나라(10월 6일), 대구 오름(10월 10일)
- **김포한강금거래소·인천 코리아금거래소**: 오늘 순금 살 때 값에 오타(7,200,000원)가 있거나 품목 이름이 그림이라 정확히 읽을 수 없어 넣지 않았습니다
- KB국민·신한·우리·NH농협 은행 골드바(공개 API 없음·접속 제한), 홈페이지가 없는 동네 금은방
이런 곳은 앱의 "내가 받은 견적 비교하기"에 가격을 넣으면 함께 비교됩니다.

## 내 주변 매장 찾기는 이렇게 동작합니다

- **매장 위치**: 각 매장 주소에서 시·도와 시·군·구를 읽습니다 ("부산광역시 진구" → 부산진구, 2026년 "전남광주통합특별시 북구" → 광주 북구처럼 줄임말·새 표기도 처리). 주소 없이 지점 이름만 공개한 곳은 이름("부평지사", "분당점")으로 짐작합니다.
- **거리**: 매장 주소를 하나하나 좌표로 바꾸려면 지도 회사 API 키가 필요해서, 통계청 시·군·구 경계로 만든 시·군·구 중심 좌표(`shared/districts.js`, 233곳)끼리의 거리를 씁니다. 그래서 거리는 "약 N km"인 대략값이고, 같은 시·군·구 안에서는 "같은 구"로 표시합니다.
- **현재 위치**: 브라우저가 알려 준 좌표는 가장 가까운 시·군·구를 고르는 데만 쓰고, 저장하거나 어디에도 보내지 않습니다. 기기에 남는 것은 고른 시·도·시·군·구 이름뿐입니다.
- **매장 가격**: 지점별 시세를 따로 공개하는 업체가 거의 없어서, 각 지점에는 그 업체 본사가 홈페이지에 고시한 오늘 가격("본사 고시가")을 붙입니다. 지점마다 조금 다를 수 있으니 방문 전에 전화로 확인하세요. 오픈 예정 매장은 순위 맨 뒤에 두고 추천하지 않습니다.

## 최저가 계산 방식

모든 구매처를 **같은 금속·같은 중량·같은 수량**으로 맞춘 뒤, 실제로 내는 돈을 더해 비교합니다.

| 구매 경로 | 총액 계산 |
| --- | --- |
| KRX 금시장 → 실물 인출 (100g·1kg만 가능) | KRX 시세 × 중량 + 매매수수료(기본 0.3%) + 인출 부가세 10% + 증권사 인출수수료 11,000원/건 + 예탁결제원 인출수수료 22,000원/개 |
| 하나은행 골드바·실버바 | 은행 고시 "고객이 살 때" 가격 + 부가세 10% (고시가 = 기준가격 × 중량 × 가산율) |
| 조폐공사·삼성금거래소·한국표준금거래소 쇼핑몰, 압구정점 골드바 | 표시 판매가 (부가세 포함 소비자가) |
| 금은방·금거래소 매장 고시가 (3.75g) | 순금 1돈 "살 때" 고시가 (부가세 별도로 표기된 곳은 10%를 더함). 골드바 제작비가 따로 붙을 수 있음 |
| 직접 입력한 견적 | 입력한 가격 (부가세 별도로 입력하면 10%를 더함) |

- "국제 시세 대비 %"는 국제 시세를 원/g으로 환산한 값(부가세 제외)과 비교한 것입니다. 실물은 부가세 10%가 항상 붙으므로 최소 +10%입니다.
- 은행 상품과 매장 고시가는 같은 곳에 되팔 때 가격(매입가)을 함께 보여 줍니다.
- KRX 수수료는 증권사마다 다릅니다(온라인 약 0.165~0.33%). 앱의 "수수료 설정"에서 바꾸세요.

### 2026년 10월 20일 오전 조사 결과 (참고)

- **순금 1돈(3.75g)**: 한국금거래소 매장 고시가 773,000원이 가장 쌌고, 하나은행 삼성금거래소 골드바(약 779,000원), 압구정점(788,000원) 순이었습니다. 쇼핑몰 디자인 골드바는 810,000원 안팎입니다.
- **금은방에 팔 때**: 순금 1돈 기준 압구정점이 683,000원으로 가장 높았고, 한국금거래소·부산 지점은 668,000원이었습니다.
- **10g·37.5g 골드바**: 하나은행에서 파는 삼성금거래소 골드바가 가장 쌌습니다.
- **100g·1kg 골드바**: KRX 금시장에서 사서 실물로 인출하는 방법이 은행·쇼핑몰·매장보다 약 4~5% 쌌습니다 (100g 기준 약 84만 원 차이). 압구정점 골드바는 은행보다 약 4% 비쌌습니다.
- **은 1kg**: 한국표준금거래소 쇼핑몰의 실버 그래뉼(알갱이) 3,018,000원, 삼성금거래소 실버바 3,080,000원이 하나은행(약 3,139,000원)·조폐공사(3,267,350원)보다 쌌습니다.

### 2026년 10월 20일 밤 조사 결과 — 지방 매장 포함 (참고)

- **순금 1돈 살 때(부가세 포함으로 맞춤) 전국 최저**는 서울이 아니라 **대구 대성금거래소 760,000원**, 그다음이 **광주감정금거래소 764,500원**(695,000원 + 부가세)이었습니다. 서울 체인 중 가장 싼 국제표준금거래소(767,000원)보다 쌉니다.
- **팔 때 가장 비싸게 사 주는 곳**: 서울 종로 K-금은거래소 680,000원, 광주감정금거래소 677,000원, 부산·대구·구미 매장들 675,000원.
- 체인 매장은 지점이 많아도 본사 고시가가 같아서, 집 근처에 지점이 있으면 서울 본점까지 갈 필요가 없습니다.

## 개발

```bash
npm run build  # GitHub Pages용 정적 사이트를 dist/에 생성 (시세를 한 번 모아 저장)
npm test     # 파서·계산 로직 테스트 (저장해 둔 실제 응답 샘플 사용, 네트워크 불필요)
npm run dev  # 파일이 바뀌면 서버 자동 재시작
```

```
server.js              Express 서버: /api/prices, 정적 파일
src/static-build.js    서버 없는 정적 사이트(GitHub Pages) 생성
scripts/build-static.js  위 기능을 실행하는 명령
.github/workflows/     GitHub Pages 자동 배포 (15분마다 시세 갱신)
src/collect.js         출처별 캐시·실패 시 마지막 데이터 유지·결과 합치기·매장 위치(시·군·구) 채우기
src/carryover.js       정적 배포 때 이번에 실패한 출처는 직전 배포 값을 이어 쓰기
src/sources/*.js       출처별 수집기 (naver, hana, komsco, kgx, ksgold, goldmarket, kgs, ssgold, goldie)
src/sources/dealers.js 사업자·개인 매장 홈페이지 23곳의 시세·판매가·매장 목록 읽기 (추가는 DEALERS 목록에 한 줄)
src/sources/shops.js   매장 고시가·쇼핑몰 상품을 비교용 구매처로 바꾸는 공통 코드
shared/compare.js      총액 계산·순위·추천 문구 (브라우저와 서버가 함께 사용)
shared/location.js     주소 → 시·도/시·군·구, 거리 계산, 내 주변 매장 가격순 정렬 (브라우저와 서버가 함께 사용)
shared/districts.js    시·군·구 중심 좌표표 (scripts/build-districts.js로 생성)
public/                화면 (index.html, app.js, chart.js, style.css)
test/                  테스트와 실제 응답 샘플(fixtures)
```

출처 사이트의 화면 구조가 바뀌면 해당 수집기가 실패하고, 앱 하단 "데이터 출처"에 실패로 표시됩니다.
이때 다른 출처의 가격으로는 계속 비교할 수 있고, 실패한 출처는 마지막으로 받은 가격을 "지연됨"으로 보여 줍니다.

## 유의사항

이 앱의 가격은 각 출처가 공개한 값을 모아 계산한 참고용 정보입니다. 실제 구매 전에 판매처에서 최종 가격·재고·수수료를 확인하세요. 투자 권유가 아닙니다.
